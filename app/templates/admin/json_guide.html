JSON Question/Answer Preparation Guide

What this import accepts

The bulk importer accepts one JSON object with three top-level keys:

  • multiple_choice (Section A)
  • short_answer (Section B)
  • long_writeup (Section C)

Questions are appended to the current exam. Existing questions are not replaced.

Complete example

{
  "multiple_choice": [
    {
      "question": "Which model focuses on online value creation from network effects?",
      "options": [
        "Value chain model",
        "Platform model",
        "Brick-and-mortar only",
        "Cost-plus model"
      ],
      "marks": 2
    },
    {
      "question": "Which statement best describes B2B e-commerce?",
      "options": [
        "Transactions between businesses",
        "Government tax filing",
        "In-person cash sales only",
        "Personal social media posts"
      ],
      "marks": 2
    }
  ],
  "short_answer": [
    "Define disintermediation in e-business and give one practical example.",
    "State two risks of relying on a single online payment provider."
  ],
  "long_writeup": [
    {
      "title": "Digital Strategy Case",
      "prompt": "A local retailer is moving online. Propose a phased e-business strategy covering channels, payments, fulfilment, and customer trust.",
      "marks": 20
    },
    {
      "title": "Governance and Compliance",
      "prompt": "Discuss how data protection obligations should influence system design choices in an online assessment platform.",
      "marks": 20
    }
  ]
}

Field rules

  • multiple_choice[].question: required text prompt.
  • multiple_choice[].options: required list with at least two options.
  • multiple_choice[].marks: optional integer, defaults to 0 if missing.
  • short_answer[]: each item is plain text prompt.
  • long_writeup[].title: optional heading shown to students.
  • long_writeup[].prompt: required long-form question.
  • long_writeup[].marks: optional integer, defaults to 0 if missing.

About answer keys

This import flow creates exam questions only. It does not import official answer keys. Student answers are collected during the test attempt and saved automatically.

Common formatting mistakes

  • Using smart quotes instead of regular JSON quotes (").
  • Leaving a trailing comma after the last item in a list.
  • Using text instead of a list for options.
  • Pasting multiple JSON objects instead of one object with the three keys.
